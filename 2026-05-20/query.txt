Part 2 ( Exporting, Importing, Dumping, and Restore)
=====================================================

   1. performed Export ,using Export tool data collected both a JSON AND CSV formats

   command in terminal: 

              - mongoexport --db=companyDB --collection=employees --out=employees.json
              - mongoexport --db=companyDB --collection=employees --type=csv --fields=empId,name,department,salary,isActive --out=employees.csv

   2. performed  dump , used dump tool for database backup . stored the full databse in BSON format for restoration 
    
    command:

           mongodump --db=companyDB --out=backup_companyDB

   3. dropped the companyDB database using drop command

   command:
    
             db.dropDatabase()

   4.  using mongorestore restored backup from dump

   command:

          mongorestore --db=companyDB backup_companyDB/

    5. then imported json file as new collection importedEmployees
     
     command: 

           mongoimport --db=companyDB --collection=importedEmployees --file=employees.json
